# Руководство по внесению вклада в AUTODIAG

## Как начать разработку

1. **Форкните репозиторий**
2. **Клонируйте форк локально:**
   ```bash
   git clone https://github.com/YOUR_USERNAME/AUTODIAG.git
   cd AUTODIAG
   ```

3. **Создайте feature branch:**
   ```bash
   git checkout -b feature/your-feature
   ```

4. **Запустите проект через Docker:**
   ```bash
   docker-compose up
   ```

5. **Внесите свои изменения**

6. **Коммитьте с понятными сообщениями:**
   ```bash
   git commit -am 'Add some feature'
   ```

7. **Запушьте в ваш форк:**
   ```bash
   git push origin feature/your-feature
   ```

8. **Создайте Pull Request**

## Правила кода

- Код должен быть читаемым и с комментариями
- Используйте типизацию в Python (type hints)
- Тестируйте ваши изменения перед отправкой
- Следуйте стилю существующего кода

## Сообщение об ошибках

Если вы нашли баг, создайте Issue с описанием:
- Как воспроизвести ошибку
- Ожидаемое поведение
- Фактическое поведение
- Скриншоты (если применимо)
