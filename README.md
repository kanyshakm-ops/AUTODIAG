# AUTODIAG - Система автодиагностики электрооборудования

🔧 Универсальный инструмент для анализа данных от различных электроизмерительных приборов (сканеры, осциллографы, мультиметры и др.)

## 📋 Возможности

- ✅ Загрузка данных от разных инструментов (напряжение, ток, сопротивление, частота, температура)
- ✅ Анализ скриншотов и отчётов от оборудования
- ✅ Автоматическая диагностика неисправностей
- ✅ Рекомендации по устранению проблем
- ✅ История всех анализов
- ✅ Поддержка интеграции с IoT устройствами в будущем

## 🏗️ Архитектура

```
AUTODIAG/
├── backend/          # Python API (Flask/FastAPI)
├── frontend/         # React приложение
├── data/            # Примеры данных
└── docker-compose.yml
```

## 🚀 Быстрый старт

```bash
# Клонируем репозиторий
git clone https://github.com/kanyshakm-ops/AUTODIAG.git
cd AUTODIAG

# Запускаем через Docker
docker-compose up
```

**Frontend:** http://localhost:3000  
**API:** http://localhost:5000

## 📊 Поддерживаемые типы данных

- 📈 Напряжение (В)
- 🔌 Сила тока (А)
- ⚡ Сопротивление (Ω)
- 📡 Частота (Гц)
- 🌡️ Температура (°C)
- 📊 Осциллограммы (графики)
- 📸 Скриншоты приборов
- 📄 Отчёты от инструментов
